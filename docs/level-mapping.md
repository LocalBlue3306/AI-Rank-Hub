# 等级映射表

## 计算逻辑

三个维度各 1-5 分 → 总分 3-15 → 映射到整体 0-10 级。

**不是简单加权平均。** 高等级设了维度门槛：某些维度不达标，总分再高也封顶。

## 维度门槛（Gating）

| 目标等级 | 使用深度最低 | 认知层次最低 | 应用广度最低 | 说明 |
|----------|-------------|-------------|-------------|------|
| Lv.4+ | 不限 | 不限 | **≥3** | 没跨出舒适区不可能到越境者 |
| Lv.6+ | **≥4** | **≥3** | 不限 | 没用过 Agent + 认知没到概念框架，不可能到召唤师 |
| Lv.7+ | **≥5** | **≥4** | **≥4** | 没自建体系 + 认知没到黑盒直觉 + 没跨界，不可能到铸造师 |
| Lv.9+ | **5** | **5** | **5** | 三维必须全部拉满 |
| Lv.10 | **5** | **5** | **5** | 三维满分 + **终极确认题通过**（见下方 Lv.9/Lv.10 区分规则） |

## 整体等级映射

### 判定规则

1. 先算三维得分
2. 检查门槛是否达标 → 不达标则封顶
3. 根据总分区间确定基础等级
4. 输出等级 + 三维雷达图数据 + 偏科标识

## Lv.9 / Lv.10 区分规则

### 为什么需要单独区分

三维量表测的是"输入与过程"（交互行为、架构认知、场景渗透），Lv.10 测的是"输出与结果"（你的 AI 系统是否已经越过了个人边界）。常规选择题无法区分——两个人在行为特征上完全相同（都是 5+5+5），但一个只服务于自己，一个已经影响他人。

### 触发条件

仅当三维得分总分 ≥13 **且** 三维门槛全部达标（深度 5 + 认知 5 + 广度 5）时，结果页额外弹出终极确认题。

### 终极确认题

> **以下哪个描述更接近你目前的状态？**
>
> - **A：** 我的 AI 系统主要服务我自己，是我的个人效率倍增器。
> - **B：** 我的 AI 产出或系统，已经有其他人或团队在依赖和使用。

- 选 A → **Lv.9 觉醒者**
- 选 B → **Lv.10 一人军团**

### 设计原则

- **不涉及商业价值、岗位替代、收入等**——避免自我报告偏差和锚定效应
- **只测一个可观测的行为事实**——你的 AI 产出是否越过了"你自己"的边界
- **非计分**——不影响三维得分，仅在结算时作为阶梯判定
- **不预设前提**——不要求"有团队"或"在做产品"，一个开源项目被人用、一个教程被人学、一个工作流被同事采用，都算 B

## 偏科画像

同一总分、不同三维组合是完全不同的人。结果页根据三维偏差自动匹配画像：

### 组合类型

| 偏科类型 | 特征 | 典型组合 | 核心问题 |
|----------|------|---------|---------|
| **机械执行者** | 深度高 + 认知低 | 深度 4-5, 认知 1-2 | 工具用得溜但不懂判断质量，容易 AI 产出什么信什么 |
| **理论派** | 认知高 + 深度低 | 认知 4-5, 深度 1-2 | 懂很多但动手少，分析头头是道实际产出少 |
| **浅尝辄止者** | 广度高 + 深度低 | 广度 4-5, 深度 1-2 | 什么领域都试过，什么领域都不深，每次都裸问 |
| **深度专家** | 深度高 + 广度低 | 深度 4-5, 广度 1-2 | 在自己一亩三分地里挖到极深，但从不出圈 |
| **纸上谈兵** | 认知高 + 广度低 | 认知 4-5, 广度 1-2 | 理解很深，但只在少数场景里用，没扩张 |
| **全能型** | 三维均衡且高 | 三维相差 ≤1 且均 ≥4 | 均衡发展，无明显短板 |
| **入门型** | 三维均衡且低 | 三维相差 ≤1 且均 ≤3 | 还在上升期，各方面都有空间 |

### 偏科判定规则

```
若任一维度与另两维均值的差距 ≥2：
  → 标记为偏科，匹配对应画像
若三维相差 ≤1 且均值 ≥4：
  → 全能型
若三维相差 ≤1 且均值 ≤3：
  → 入门型
否则：
  → 发展中（无明显偏科但也不均衡）
```

### 偏科画像 → 针对性建议方向

| 画像 | 建议方向 |
|------|---------|
| 机械执行者 | 补认知：学 AI 基础原理、建验证流程、练"什么时候不信任 AI"的判断力 |
| 理论派 | 补深度：少看多练，建自己的 Prompt 库，找一个场景挖到 Lv4 |
| 浅尝辄止者 | 补深度：选定 1-2 个最高频场景，停下来建工作流，不要继续扩张 |
| 深度专家 | 补广度：用 AI 试一件跟你专业完全无关的事，不需要做很深，先跨出去 |
| 纸上谈兵 | 补广度+深度：把已有的认知变成实际产出，扩到没试过的领域 |
| 入门型 | 先提深度：学会追问、给角色指令、结构化 Prompt，从 Lv1 推到 Lv3 |
| 全能型 | 向 Lv9-10 冲刺：三维已高，差距在判断力、审美、价值排序（非 AI 层面） |


## 边界情况处理

| 情况 | 处理方式 |
|------|---------|
| 深度 5+认知 5+广度 2 → 总分 12 | 广度门槛不满足 Lv7+，封顶 Lv6。标注"深度专家"偏科 |
| 深度 1+认知 5+广度 5 → 总分 11 | 深度 1 意味着基本没用过 AI，但认知和广度很高——理论上不可能。题目设计应避免此组合（认知题依赖实际使用经验） |
| 深度 5+认知 1+广度 5 → 总分 11 | 同上，认知 1 的人不可能深度 5。题目设计阶段需验证三维相关性下限 |
| 总分相同但组合不同 | 偏科画像自动区分，不依赖总分排序 |
