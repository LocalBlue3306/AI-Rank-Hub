# 等级映射表 v2

## 架构总览

三层分离：

- **底层算法层**：三个维度独立判分（1-5） → 门槛判定 → Core Tier → 展示等级。对外不暴露。
- **前端展示层**：10 级成长体系（Lv.0-10），保留命名、画像、传播性。
- **结果解释层**：偏科画像 + 最低维度优先建议，告诉用户为什么是这个等级、下一步怎么升。

---

## 1. 底层算法层

### 1.1 输入

三个维度各自独立判为 1-5 级，不做题内互相补偿：

- **D** = 使用深度
- **C** = 认知层次
- **B** = 应用广度

### 1.2 判定流（纯门槛驱动，无加权公式）

按优先级从上到下匹配，命中即停：

```
1. IF D=5 AND C=5 AND B=5:
      → Core-5
      弹终极确认题 → A: Lv.9 觉醒者 / B: Lv.10 一人军团

2. ELSE IF D≥5 AND C≥4 AND B≥4:
      → Core-4
      总分 13 → Lv.7 铸造师
      总分 ≥14 → Lv.8 造物主 (Core-4 封顶)

3. ELSE IF B≥3 AND D≥3:
      → Core-3
      总分 ≤8 → Lv.4 越境者
      总分 ≥9 AND D≥4 AND C≥3 → Lv.6 召唤师 (Core-3 封顶)
      总分 ≥9 → Lv.5 织网者 (兜底，捕获 gate 失败的高分组合)

4. ELSE IF D≥2:
      → Core-2
      总分 ≤5 → Lv.2 对话者
      总分 ≥6 → Lv.3 驯化师 (Core-2 封顶)

5. ELSE:
      → Core-1
      总分 ≤3 → Lv.0 旁观者
      总分 ≥4 → Lv.1 尝鲜者 (Core-1 封顶)
```

### 1.3 门槛对照表

| Core Tier | 进入门槛 | 门槛含义 | 对应展示等级 |
|-----------|---------|---------|-------------|
| Core-5 | D=5, C=5, B=5 | 三维全满 | Lv.9-10 |
| Core-4 | D≥5, C≥4, B≥4 | 自建体系 + 黑盒直觉 + 跨界 | Lv.7-8 |
| Core-3 | B≥3, D≥3 | 跨出舒适区 + 结构化使用 | Lv.4-6 |
| Core-2 | D≥2 | 会多轮对话 | Lv.2-3 |
| Core-1 | (默认) | 入门或单次使用 | Lv.0-1 |

### 1.4 设计原则

- **门槛是绝对的**：不满足门槛的组合，总分再高也封顶在对应 Core Tier 以下
- **无加权公式**：不用 S = 0.4D + 0.4C + 0.2B 等连续分。三维是离散的，门槛判定本身就承载了权重——深度和认知在 Core-3/4 入口处权重自然更高，广度在 Core-3 入口处是强制闸门
- **Core Tier 只用于算法层**：不暴露给用户，避免用户困惑"为什么我是 Core-4 但等级是 Lv.7"

## 2. 前端展示层

### 2.1 展示等级含义

| 等级 | 名称 | 一句话画像 |
|------|------|-----------|
| Lv.0 | 旁观者 | 听过 AI 但没用过 |

## 3. Lv.9 / Lv.10 区分规则

### 3.1 为什么需要单独区分

三维量表测的是"输入与过程"，Lv.10 测的是"输出与结果"——AI 系统是否已经越过了个人边界。常规选择题无法区分两个行为特征完全相同的人（都是 5+5+5），区别只在一个服务自己，一个服务他人。

### 3.2 触发条件

仅当 `D=5 AND C=5 AND B=5` 时，结果页额外弹出终极确认题。

### 3.3 终极确认题

> **以下哪个描述更接近你目前的状态？**
>
> - **A：** 我的 AI 系统主要服务我自己，是我的个人效率倍增器。
> - **B：** 我的 AI 产出或系统，已经有其他人或团队在依赖和使用。

- 选 A → **Lv.9 觉醒者**
- 选 B → **Lv.10 一人军团**

### 3.4 设计原则

- 不涉及商业价值、岗位替代、收入——避免自我报告偏差
- 只测一个行为事实：产出是否越过了"自己"的边界
- 非计分，不影响三维得分
- 不预设前提——开源项目被人用、教程被人学、工作流被同事采用，都算 B

## 4. 偏科画像层

### 4.1 判定规则

```
若任一维度与另两维均值的差距 ≥ 2：
  → 标记为偏科，匹配对应画像
若三维相差 ≤ 1 且均值 ≥ 4：
  → 全能型
若三维相差 ≤ 1 且均值 ≤ 3：
  → 入门型
否则：
  → 发展中（无明显偏科但也不均衡）
```

### 4.2 画像类型

| 画像 | 条件 | 一句话诊断 |
|------|------|-----------|
| 机械执行者 | D 高, C 低 | 工具用得溜但不懂判断质量，AI 说什么信什么 |
| 理论派 | C 高, D 低 | 懂很多但动手少，分析头头是道实际产出少 |
| 浅尝辄止者 | B 高, D 低 | 什么领域都试过，什么领域都不深，每次都裸问 |
| 深度专家 | D 高, B 低 | 在自己一亩三分地里挖到极深，但从不出圈 |
| 纸上谈兵 | C 高, B 低 | 理解很深，但只在少数场景用，没扩张 |
| 全能型 | 三维均衡且高 (均≥4) | 均衡发展，无明显短板 |
| 入门型 | 三维均衡且低 (均≤3) | 全面起步阶段 |
| 发展中 | 不偏科也不均衡 | 正在形成稳定的能力结构 |

## 5. 建议生成逻辑

**按最低维度优先发建议。** 不按总等级发，不看"你是什么画像所以你要怎样"的泛泛而谈。

### 5.1 若深度最低

建议方向：
- 学会追问和补充背景——AI 答得不好时不要直接放弃
- 给自己最高频的 3 个场景各写一个固定 Prompt 模板
- 为一个重复性任务搭建固定工作流，从"每次裸问"升级到"模板驱动"

### 5.2 若认知最低

建议方向：
- 每次使用 AI 强制加一步验证——事实类数据自己核实，代码跑一遍
- 学会诊断"这次为什么出错"——是 Prompt 问题还是模型局限
- 了解幻觉的常见模式、不同模型的核心差异、什么时候该信任/不该信任 AI

### 5.3 若广度最低

建议方向：
- 从当前主场景外，再扩 2-3 个稳定使用场景
- 选一个跟自己专业完全无关的小项目，用 AI 做出完整结果
- 不追求多装工具，先追求跨类别任务迁移

### 5.4 若三维均高

建议方向：
- 从"自己高效"走向"让别人也能复用"——把经验封装成模板、知识库或 SOP
- 思考你的 AI 系统能不能服务更多人——开源、教程、团队推广

## 7. 边界情况处理

| 组合 | 判定路径 | 结果 | 说明 |
|------|---------|------|------|
| D=1, C=1, B=1 (总 3) | Core-1, 总≤3 | **Lv.0** | 旁观者 |
| D=2, C=1, B=1 (总 4) | Core-2 (D≥2), 总≤5 | **Lv.2** | 注意：总 4 但 D≥2，先命中 Core-2 |
| D=2, C=2, B=1 (总 5) | Core-2, 总≤5 | **Lv.2** | 刚学会对话，广度为零 |
| D=3, C=2, B=1 (总 6) | Core-2, 总≥6 → 封顶 Lv.3 | **Lv.3** | 结构化使用但没跨出舒适区 |
| D=3, C=2, B=3 (总 8) | Core-3, 总≤8 | **Lv.4** | 刚跨出舒适区 |
| D=4, C=3, B=3 (总 10) | Core-3, 总≥9 AND gate → Lv.6 | **Lv.6** | Agent 跃迁 |
| D=4, C=2, B=4 (总 10) | Core-3, 总≥9 不满足 gate → 兜底 Lv.5 | **Lv.5** | 广度深但认知低，gate 拦截 |
| D=3, C=5, B=5 (总 13) | Core-3, 总≥9 不满足 D≥4 → 兜底 Lv.5 | **Lv.5** | 认知广度双高但深度低，标"理论派" |
| D=5, C=5, B=4 (总 14) | Core-4, 总≥14 | **Lv.8** | 造物主 |
| D=5, C=4, B=4 (总 13) | Core-4, 总=13 | **Lv.7** | 铸造师 |
| D=5, C=5, B=5, 终极题 B | Core-5, 选 B | **Lv.10** | 一人军团 |
| D=5, C=5, B=5, 终极题 A | Core-5, 选 A | **Lv.9** | 觉醒者 |
| D=5, C=4, B=2 (总 11) | Core-2 (B=2 不满足 Core-3), 总≥6 → Lv.3 | **Lv.3** | 深度认知双高但 B=2 不满足 B≥3，封顶 Core-2。标"深度专家" |
| D=5, C=1, B=5 (总 11) | Core-3 (B≥3, D≥3), 总≥9 不满足 C≥3 → 兜底 Lv.5 | **Lv.5** | 理论上不可能组合（深度 5 的人认知不可能 1）。如真实出现，标"机械执行者"，建议补认知 |

## 8. V1 → V2 迭代计划

### V1 上线
- 当前判定流 + 题目（单选，不做自适应）
- 结果页展示等级、雷达图、偏科画像、建议

### V2 校准
- 收集真实答题分布，检查三维相关性
- 验证异常组合是否出现（如 D=5, C=1）
- 调整题目权重和各等级分界线

### V3 增强
- 增加一致性校验题（正反向题交叉验证）
- 分群解释（学生 / 职场 / 开发者 / 创作者）
- 终极确认题有效性验证

## 9. 与 v1 的核心差异

| | v1 (level-mapping.md) | v2 (本文件) |
|---|---------------------|------------|
| 映射方式 | 总分直接映射到 10 级 | Core Tier 先定大段，段内总分定位置 |
| 有无公式 | 无 | 无（坚持无加权公式） |
| 门槛一致性 | 总分映射表与门槛存在冲突 | 门槛优先，总分在段内生效 |
| 建议逻辑 | 按偏科画像匹配 | 按最低维度优先 |
| 算法/展示分离 | 未分离 | Core Tier 对内，展示等级对外 |
